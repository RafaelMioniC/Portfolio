API 01 · PROJETO EM GRUPO

Radar Cidadão

Grupo: NoClip

Empresa parceira

Fatec (simulado para entendermos o funcionamento de uma API)

Problema identificado

A dificuldade de reunir, consultar e acompanhar informações sobre a atuação dos deputados, incluindo gastos públicos, votações e presença nas atividades parlamentares.

Tecnologias utilizadas

Flask, Python, HTML, CSS, JavaScript, Bootstrap e API da Câmara dos Deputados.

Solução desenvolvida

Desenvolvimento de uma plataforma informativa que apresenta dados dos deputados, permitindo consultar informações sobre gastos, votações e presença parlamentar. Também foram utilizados gráficos desenvolvidos em Python com dados provenientes da API da Câmara dos Deputados.

Contribuições pessoais

Códigos em Python para manipulação dos dados, criação de gráficos e integração com a API da Câmara dos Deputados.

Hard skills adquiridas

Desenvolvimento de APIs REST, Flask, Python e integração com APIs externas.

Soft skills exercitadas

Comunicação, colaboração, organização, resolução de problemas e trabalho em equipe

API 02 · PROJETO EM GRUPO

Sistema de Gestão de Projetos

GesTec

Empresa parceira

Altave

Problema identificado

A necessidade de centralizar o gerenciamento de clientes, projetos e Ordens de Serviço (OS), permitindo organizar as demandas de cada cliente, acompanhar o andamento dos projetos e controlar as atividades vinculadas a eles. A falta de integração entre essas informações dificulta o acompanhamento de prazos, a distribuição de responsabilidades e a visualização do progresso das atividades.

Tecnologias utilizadas

Node.js, Express, TypeScript, Prisma ORM, MySQL e JWT.

Solução desenvolvida

Desenvolvimento de um sistema web de gestão de projetos, permitindo o cadastro e gerenciamento de clientes, a criação e vinculação de projetos e o gerenciamento de Ordens de Serviço (OS) relacionadas a cada projeto. A plataforma oferece recursos para organizar demandas, atribuir responsáveis, acompanhar o andamento das atividades, gerenciar prioridades e controlar prazos de entrega, facilitando o planejamento e a execução dos projetos.

Contribuições pessoais

Responsável pela criação dos mockups das interfaces, desenvolvimento do frontend e integração com a API do sistema. Atuação na estruturação das telas, implementação dos componentes visuais e conexão entre a interface e os serviços do backend, garantindo a comunicação e o funcionamento das funcionalidades da plataforma.

Hard skills adquiridas

Desenvolvimento de interfaces web (Frontend), criação de mockups e prototipagem de interfaces com Figma, desenvolvimento de componentes utilizando React e TypeScript, estilização com CSS e integração entre frontend e APIs REST, incluindo consumo de endpoints e tratamento de dados provenientes do backend.

Soft skills exercitadas

Comunicação, colaboração, divisão de tarefas, organização, resolução de problemas e trabalho em equipe.
